# Marketing v0.1

An operator creates a campaign, publishes its content and SEO metadata to a designated website page,
then ends it to restore that page's baseline. Marketing remains a standalone institution.

## Scope

- Campaign target website and intake URL, audience, objective, and call to action.
- Website copy, imagery, featured offering references, and SEO/social metadata, including relevant structured data.
- Durable storage and an authorized management interface.
- Draft, active, and ended states; manual publish, republish, and end actions.
- One active campaign per website and intake URL; conflicting publication is rejected.
- Published content is a snapshot. Draft edits do not alter the live page.
- Hosts render supported campaign fields and preserve their baseline content for restoration.
- Integration into Black Circuit and Aetheric Forge public/admin applications by convention.

Automatic scheduling, analytics, attribution, A/B testing, and external marketing channels are deferred.

## Milestones

Current progress: the institution foundation is complete inside this repository. Model/storage
is implemented and tested. Host wiring is deferred until the published document shape and operations
exist, so convention-based hosts can integrate a meaningful reader rather than an empty runtime dependency.

1. **Institution foundation.** Repository, runtime identity and plugin, pinned dependencies,
   and integration documentation. Runtime discovery and mounting verified in tests. Actual application
   wiring remains an acceptance item; the Black Circuit hosts currently use the Mongo convention,
   not a runtime loader. Do not add a runtime requirement to the public site merely to read content.
2. **Campaign model and storage.** Establish the durable document schema and validation. Create,
   edit, save, and retrieve campaigns. Incomplete publication content and invalid intake URLs are rejected.
3. **Management.** Authorized admin interface and explicit publish/republish/end operations.
   Publish a snapshot and enforce per-target exclusivity. Private notes and draft edits stay unpublished.
4. **Website integration.** Public readers and supported page fields in both websites. Begin with
   Black Circuit `/portfolio`; select Aetheric Forge's initial page during integration. Ending a campaign
   restores baseline copy and metadata. Keep the public site functional without Mongo configured.
5. **Acceptance and release.** Verify create → edit → publish → inspect content/metadata → end →
   inspect restoration on both hosts; document operation and deployment.

## Existing Black Circuit work

The existing admin Campaign CRUD is internal tracking: status, channel, dates, budget, offering references,
and notes. It is a starting point for UI and persistence conventions, not the complete Marketing model.
Define a compatible migration before changing existing campaign documents. Intake URLs, website content,
publication snapshots, SEO metadata, and lifecycle operations still need implementation.

## Release acceptance

Run and end a campaign on each website through Marketing without manually editing website files.
Verify authorization, conflicting publication, republishing, private/draft content isolation, and restoration.
